CODIGO FUENTE CORRESPONDIENTE — FFmpeg.wasm
=============================================

Este sitio distribuye un binario de FFmpeg compilado a WebAssembly. La GPL
exige que se acompanie del codigo fuente correspondiente. Este manifiesto indica
exactamente cual es y como reconstruirlo.

BINARIO DISTRIBUIDO
-------------------
  Fichero      : public/assets/wasm/ffmpeg-core.wasm
  Version      : @ffmpeg/core 0.12.10
  SHA-256      : 9f57947a5bd530d8f00c5b3f2cb2a3492faa7e5d823315342d6a8656d0a6b7b7
  Licencia     : GPL-2.0-or-later
  Variante     : GPL (--enable-gpl --enable-libx264 --enable-libx265)
  Upstream     : git+https://github.com/ffmpegwasm/ffmpeg.wasm.git
  Version FFmpeg: 5.1.4
  Emulador     : Emscripten 3.1.40

El binario NO ha sido modificado por este proyecto: se copia tal cual desde el
paquete npm @ffmpeg/core 0.12.10. El hash SHA-256 permite verificarlo.

CONFIGURACION DE COMPILACION
-----------------------------
  configuration: --target-os=none --arch=x86_32 --enable-cross-compile --disable-asm
  --disable-stripping --disable-programs --disable-doc --disable-debug
  --disable-runtime-cpudetect --disable-autodetect --nm=emnm --ar=emar --ranlib=emranlib
  --cc=emcc --cxx=em++ --objcc=emcc --dep-cc=emcc --extra-cflags='-I/opt/include -O3 -msimd128'
  --extra-cxxflags='-I/opt/include -O3 -msimd128' --disable-pthreads --disable-w32threads
  --disable-os2threads --enable-gpl --enable-libx264 --enable-libx265 --enable-libvpx
  --enable-libmp3lame --enable-libtheora --enable-libvorbis --enable-libopus --enable-zlib
  --enable-libwebp --enable-libfreetype --enable-libfribidi --enable-libass --enable-libzimg

PARA RECONSTRUIR EL BINARIO
----------------------------
  git clone https://github.com/ffmpegwasm/ffmpeg.wasm.git
  cd ffmpeg.wasm && git checkout v0.12.10
  docker build -t ffmpeg-wasm .
  # El resultado se copia a public/assets/wasm/ffmpeg-core.{js,wasm}
